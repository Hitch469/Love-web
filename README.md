# ❤️ About

**Love Web** is an interactive romantic website created as a heartfelt digital gift.

Instead of writing a traditional love letter, this project transforms memories into an immersive web experience filled with beautiful animations, floating hearts, music, interactive photo galleries, and emotional storytelling.

Each chapter represents an important moment in a relationship, creating a unique and memorable experience for the person receiving it.
